# 技能模式电脑：十级能力认证表（v0.1 草案，待 Ham 审批）

- 起草：Claude Code（AI 增强），2026-10-17。依据：Ham 的分级设想（一级只会基础象棋 → 二级加升级和技能 → 三级加军功管理 → 七八级起掌握战术 → 十级完美），以及现有考卷 `bfai_exam.js`（41 道机制题）和 `bfai_exam_games.json`（25 道实战题）。
- 这是**同一个电脑的认证级别**，不是十个不同的电脑：每做出一个新版本，就去考试，考到第几级就认证到第几级。
- 目的：让“完美电脑”可检查。电脑到位了，自对弈得出的平衡数据才可信（Ham 10-10：“先训练出尽可能完美理解机制的人机电脑，这样我们才能拿到正确的数据”）。

## 一、通用规则

### 1. 怎样算过一级
1. **本级考题**：每题用不同随机种子考 3 次，总分 ≥ 90%；任何一题不得 0/3；“会防”题每题至少 2/3。
2. **低级不退步**：以前各级的考题总分比上一认证版本最多少 2 分。
3. **对打不吃亏**：对上一个认证版本下 600 局（同种子、换边），不能明显变弱（z > −1）。**七级起**每升一级还要明显变强（z ≥ 2）：战术学会了，就应当赢得更多。
4. 考试条件固定：霸王档、每步 10 万节点（按节点数收手，结果可复现，量级接近网页里霸王 3 秒）。

### 2. 题目规则
1. 一题只考一个机制，无关的兵法设为已用，免得干扰。
2. **每个机制都要有“会用”和“会防”两种题**：会用 = 该出手时出手；会防 = 对方能这么干时提前防住。
3. 每题必须先过 `--lint`（局面合法、标准答案判对、错误示范判错），再过 `--verify`（长时间深搜复核标准答案）。深搜不同意的题交 Ham 裁决。
4. **留一半题不公开**：每级题分成“练习题”和“考试题”。改电脑时只看练习题，认证时考考试题，防止电脑只会做题、不会下棋。
5. 高阶战术不是让电脑背棋谱：每条战术都要转成考题（会用、会防各一）；必要时再加进打分公式或搜索规则，让电脑认得这一类局面，换个位置也认得。

## 三、第十级（完美）的判定
真正的“完美”无法证明，所以用可检查的条件代替：
1. 一到九级考试题全部过线；
2. 前任数值部定的四条“到位标准”全部满足：
   - 新版对上一版 < 55%（再改也强不了多少）；
   - 两版电脑自对弈的汉方胜率相差 ≤ 3 个点；
   - 技能使用率在两版之间稳定；
   - 考卷不退步；
3. 复盘 Ham 和电脑的真实对局，没有重大错误。

满足这些，就是“再变强，平衡数据也不再变”：拿它跑出来的平衡数据才可信。

## 七、九级“计划题”的格式（v0.1）

单步考题考不出长计划，九级改成**从一个局面开始下一段，看结果**：

| 字段 | 说明 |
|---|---|
| 局面 | `{src, opts, S}`，和战术题一样；最好是实战里收的 |
| 被考的一方 | `side` |
| 对手 | 固定为线上霸王（`cf0833`），同样的节点数 |
| 下几回合 | `horizon`，一般 8～15 回合（16～30 手） |
| 局数 | 同一局面换 10 个随机种子下 10 段（电脑有 0.05 的随机，段段不同） |
| 量什么 | `metric`：`win`（直接下完看胜负）、`material`（下完那一刻的中立局面分）、`merit`（双方军功流向，T7 / T9 这类节奏战术用）三选一 |
| 怎么算过 | 和“参照电脑”从同一局面、同样种子下的结果比：比参照好、且 10 段里至少 7 段不差 |
| 参照电脑 | 上一个认证版本；第一次用线上霸王 |

- 战术部门交计划题时给：局面、`side`、`horizon`、`metric`、这条计划的意图（例：“连将逼楚花钱，第 10 回合前楚军功少 10 以上”），以及期望的方向。
- 判卷工具我来写（基于 `bfsim.js`，加“从给定局面开始、限回合”的选项）。
