## 状态词含义

- **已验证**：必须连同具体对象、版本、范围和证据类型阅读。回放验证、只读审计、独立运行是不同强度的证据。
- **待验证**：没有足够证据确认；不能用计划、脚本存在或任务创建替代实际运行记录。
- **已撤回**：历史结论保留在纠正史中以便追溯，但不得再作为当前推论的前提。
