## 阅读边界

- 手册中的局面是人工构造的合法状态，除非另有证据，不声称可从标准开局自然到达。
- “强制组合”只指已验证短树内的规则结算；“诱骗”依赖对手选择，不得写成必胜。
- v0.2 明确保留最佳直接反制和失败分支：主动践踏陷阱对有限视野/贪子应对有效，但没有通过强防守门槛。
- 当前证据只覆盖有界的即时行动树，没有穷尽十手、十回合或整盘最优分支。
- 未附原始私人日志、测试账号资料、生产源码或训练候选。
